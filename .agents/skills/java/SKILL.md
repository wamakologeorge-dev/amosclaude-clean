## 📐 Conventions & Best Practices

### Compiled Rules
- 📐 **Always:** Use constructor injection — not field injection (@Autowired on field)
  - _Constructor injection makes dependencies explicit and enables immutability_
- 📐 **Always:** Layer architecture: @Controller → @Service → @Repository — never skip layers
  - _Calling repository from controller breaks testability and separation of concerns_
- 📐 **Always:** Never expose JPA entities directly as REST response — use DTOs
  - _Entities expose internal schema, lazy fields, and circular references to clients_
- 📐 **Always:** Use Optional<T> as return type instead of null for repository findBy methods
  - _Forces callers to handle missing values explicitly_
- 📐 **Always:** Keep @Service methods free of HTTP concerns (no HttpServletRequest)
  - _Services must be reusable from CLI, tests, or other transports_
- ✅ **Always:** Use @DataJpaTest for repository tests — it loads only JPA context
  - _Faster than @SpringBootTest for data layer testing_
- ✅ **Always:** Use @MockBean in Spring tests to replace real beans with mocks
