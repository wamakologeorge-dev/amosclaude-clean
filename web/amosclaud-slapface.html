    Secret-leak rule

    Slapface does not block merely because a string is long or contains the word token. A hard block requires high-confidence evidence such as a recognized provider key format or multiple agreeing signals: secret-name context, realistic length, character diversity, and entropy. Placeholders and lower-confidence values are warnings only.

    Suspected credentials are redacted. Slapface stores a short fingerprint and masked preview, not the raw secret.
