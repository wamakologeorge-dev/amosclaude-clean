Execution path

  1. Authorize user and repository
  2. Create one cooperation pipeline from the request
  3. Match each task to an eligible worker or controlled cloud lane
  4. Plan, implement, test, and self-correct in isolation
  5. Record artifacts, logs, approval decisions, and verification evidence
  6. Open a draft pull request or return the verified result for human sign-off
