# Amosclaud license scope

Amosclaud intentionally uses more than one license. **The root `LICENSE` remains the MIT License** for repository material that is not expressly assigned another license.

## MIT — the open Amosclaud wall

The root `LICENSE` remains unchanged. Files that do not carry another explicit license notice continue to use the repository's applicable MIT terms, subject to any third-party notices that already apply to them.

## Important transition rule

This scope statement is prospective. It does **not** revoke permissions that were already granted for a particular copy or version under MIT or another earlier license. Newly designated Book versions and newly created Book-specific files should carry the Book license identifier so developers can determine the applicable terms without guessing.

## Third-party components

Third-party code, libraries, fonts, media, models and other dependencies remain governed by their own licenses. An Amosclaud license notice never overrides third-party rights.
