# Autonomous Engineering Workforce Roadmap

## Phase 1 — Governed ownership foundation

- durable epic, feature, bug, refactor, maintenance, test, and review delegations;
- explicit write approval;
- one Amosclaud Autonomous core;
- isolated GitHub branches;
- bounded self-correction;
- deterministic verification;
- rollback checkpoint;
- verified draft pull request;
- human final merge;
- software asset telemetry and health aggregation;
- explicit edge-runner capability contract;
- immutable guardrails.

## Phase 2 — Native repository parity

- native Amosclaud work branches;
- native pull requests and review evidence;
- native rollback and branch protection;
- optional GitHub publication after native verification;
- one delivery timeline shared across native and GitHub-backed repositories.

## Phase 3 — Complete private edge execution

- signed desktop and Linux station installers;
- repository execution claim/completion client;
- Docker/Kata/Firecracker isolation profiles;
- runner attestation and image identity;
- local folder bridge with conflict detection;
- resumable execution and encrypted local secret references;
- workload scheduling by capability, resource availability, locality, and policy.

## Phase 4 — Autonomous asset operations

- server-managed health probes;
- deployment log and metric connectors;
- automated incident diagnosis;
- bounded maintenance delegations from verified incidents;
- Railway, Render, AWS, and GCP deployment adapters;
- approval-gated rollback and release promotion;
- SLOs, budgets, usage, and revenue views.

## Phase 5 — Transferable software assets

- signed asset packages and provenance;
- dependency and license inventory;
- recipient policy validation;
- secret and domain re-authorization workflow;
- licensing, transfer, and support agreements;
- marketplace or investment workflows only after legal, billing, escrow, and compliance review.

Every phase retains the same immutable principles: no fabricated success, no force push, no protected-branch write, no automatic merge, no credential leakage, and no production deployment without human approval.
